# bazis-statusy 2.11.0

Requires Bazis 2.14.

## Changes

- The lazy texts of the JSON schemas of a transit payload (`Field(title=_('…'))`) are
  translated by the mechanism of the core: the payload type and
  `TransitActionEndpointBodySchema` inherit `TranslatedSchemaModel` of
  `bazis.core.utils.schemas`, whose `model_json_schema()` uses `TranslatedJsonSchema` of
  the core. The own `TranslatedJsonSchema` of the package is removed;
  `bazis.contrib.statusy.schemas.TranslatedSchemaModel` still imports, as the class of the
  core. The schemas are the same as with 2.10.
