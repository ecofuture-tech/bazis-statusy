# bazis-statusy 2.6.1

Requires bazis 2.10.0 and bazis-permit 2.4.1.

## Fixes

- **No Pydantic deprecation warning.** `TransitActionSchema` (the state actions of an
  item) declared its example with `Field(example=...)`, deprecated by Pydantic 2: every
  project that imports the package got `PydanticDeprecatedSince20` in its tests. It is
  `Field(examples=[...])` now; the JSON schema has `examples` instead of `example`.

## Documentation

The guide (`bazis/contrib/statusy/AGENTS.md`) and the manifest answer what the agent of a
trial read the sources for: a transit in code (`get_transit`, what `transit_apply` does
and does not check), its actor (the author of the history record; `None` for a transit
the system makes), an automatic transit on create in `hook_after_create` (validated with
the create; validate the item first with `scope.validate()` so that an invalid item
answers with the errors of its fields, not with `ERR_TRANSIT`, and the item is then
validated twice, as `create` and as `transit`), the history
(`statusy_transits`) and the status fields the route already leaves out of the create and
the update.
