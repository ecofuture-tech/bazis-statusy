# bazis-statusy 2.5.0

Requires bazis 2.9.0 and bazis-permit 2.4.1.

## Features

- **A transit validates the item once: `JsonApiMixin.validate_item` with the source
  `transit`.** bazis 2.9.0 checks the invariants of an item on every write
  (`validate_item(changes)`); a transit saves the item several times (its actions, then
  the status), and each save was validated alone, as a plain `save`, before the transit
  was complete. `transit_apply` now declares the transit
  (`bazis.core.item_validation.defer_validate_item(item, source='transit', user=user)`):
  the item is validated once, after the actions after the status, with the changes of all
  the saves (`status`, `status_dt`, `status_author` and the fields the actions set) and
  the user of the transit; inside a route (the transit endpoint, a transit in
  `hook_after_create`) at the end of the request. A failure rolls the transit back, the
  history record included; the transit endpoint answers 422 `ERR_ITEM_INVALID`.
