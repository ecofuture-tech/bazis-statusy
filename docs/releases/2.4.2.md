# bazis-statusy 2.4.2

Requires bazis 2.4.2 and bazis-permit 2.4.1.

## Fixes

- **The name of a status or a transit is "Название" in Russian**, as in bazis-permit: the
  catalog of the package translated the msgid `"Name"` as "Наименование". When two catalogs
  translate the same msgid, the first one in `LOCALE_PATHS` wins, so the title of the field
  depended on the packages a project installed and on their order. The Bazis packages now
  share the translation; a project that prefers another one translates `"Name"` in its own
  `locale`.
