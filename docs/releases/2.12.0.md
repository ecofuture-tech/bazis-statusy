# bazis-statusy 2.12.0

Requires bazis 2.16 and bazis-permit 2.11.

## Breaking changes

- **The transit is closed to anonymous users.** `POST /{item_id}/transit/` is an action of
  bazis-permit declared `public=False`: an anonymous user gets 403 even with a transit
  permission of a role for anonymous users. A transit for anonymous users is a route of its
  own with `action_transit = route_declare(StatusyRouteSetBase.action_transit,
  public=True)` (bazis 2.16, see the guide); the transit then has no author (it failed with
  a 500 storing the anonymous user before).
- **`statusy.W002` is removed.** The untranslated names of the declared statuses and
  transits are listed by `manage.py bazis_messages status` of the core.

## Changes

- **`Workflow(initial=...)`**: the status of a new object of the model created without one
  (the API, `Model()`, `objects.create()`), instead of the global `BAZIS_STATUS_INITIAL`;
  an initial status that is not a status of the workflow is `statusy.E001`.
- `GET /{item_id}/schema_transit/` is of kind `schema` in `x-bazis`.
- The declarations use the helpers of the core, `bazis.core.declare` (bazis 2.16), instead of
  those of bazis-permit.
